หน้าต่างที่ 1: เปิดเซิร์ฟเวอร์ Backend (API & ฐานข้อมูล)
เปิด Terminal แล้วพิมพ์คำสั่งเพื่อเข้าไปในโฟลเดอร์ Backend:
node server.js
(หากสำเร็จ มันจะขึ้นข้อความแจ้งว่าเซิร์ฟเวอร์กำลังทำงานอยู่ที่พอร์ต 5000 และเชื่อมต่อฐานข้อมูลสำเร็จ)

หน้าต่างที่ 2: เปิดหน้าเว็บ Frontend (React/Vite)
เปิด Terminal อันใหม่ (เปิดแยกอีกอัน) แล้วพิมพ์คำสั่งเพื่อเข้าไปในโฟลเดอร์หน้าเว็บ:
npm run dev
(รอสักครู่ ระบบจะสร้างลิงก์ขึ้นมา ให้คุณกดปุ่ม Ctrl ค้างไว้ แล้วคลิกที่ลิงก์ http://localhost:5173 เพื่อเปิดหน้าเว็บได้เลยครับ)
